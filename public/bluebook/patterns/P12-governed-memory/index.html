    P12 治理化Memory写入¶

    Release Candidate 1

    主要章节：第5、12章

    Context¶

    Agent希望跨会话保留偏好、事实或承诺。

    Problem¶

    自动记忆会持久化误解、攻击内容和敏感数据。

    Forces¶

    • 质量与正确性；
    • 延迟与成本；
    • 安全与合规；
    • 运维与可恢复性。

    Solution¶

    候选提取→分类→来源校验→同意/政策→冲突处理→版本化写入；支持查看、更正和删除。

    Consequences¶

    收益¶

    获得持续个性化且保留用户控制。

    代价¶

    写入延迟和治理成本增加。

    Failure Modes¶

    把所有对话自动向量化；Memory覆盖权威数据库。

    Implementation Sketch¶

    实现时使用类型化输入输出，记录版本、来源和Trace；权限、预算和终止由确定性代码执行。

    Evidence¶

    • 蓝皮书章节：第5、12章；
    • 实验卡：按具体实现绑定，不以代码存在替代运行证据；
    • 外部标准：涉及协议或安全标准时在发布前核验版本与日期。

    Exit Criteria¶

    无需跨会话个性化时不写长期Memory。

    Checklist¶

    • [ ] 问题与作用力真实存在。
    • [ ] 有更简单方案基线。
    • [ ] 失败模式可测试。
    • [ ] 权限、预算和恢复已定义。
    • [ ] 收益覆盖新增复杂度。
